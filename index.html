About me

I'm a full-stack developer with nearly ten years building and modernising business systems with .NET 8 / C#, Angular, SQL Server and Entity Framework Core, mostly for the public sector and regulated utilities.

I'm now moving into an IT Innovation role. My current focus is Retrieval-Augmented Generation (RAG) with local, on-premise LLMs: AI that can run where the data has to stay. I care about the engineering around the model as much as the model itself: CI/CD on Azure DevOps, observability with Application Insights, resilient distributed architecture, and tests you can trust.

I also like to look at AI answers with a critical eye. A good assistant is one you can check, so I build tools that show their sources.
